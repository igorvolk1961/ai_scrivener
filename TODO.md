# TODO

Реестр согласованных заглушек. Правило (NFR-015, `guides/development.md`): заглушки (`TODO`, `FIXME`, `XXX`, `HACK`, `NotImplementedError`, «заглушка», `stub`) в `src`, `rag-service/src`, `scripts` запрещены пре-коммитом безусловно, кроме одного исключения — строка с маркером одновременно содержит ссылку `TODO.md#T-NNN` на запись в этом файле, и такая запись здесь существует (заголовок `### T-NNN`). Без обеих частей коммит блокируется.

Новая запись создаётся только:

- в крайнем случае, когда альтернативы хуже (не «было лень доделать»);
- по согласованию с пользователем в текущей сессии — запись фиксирует, что согласование было, а не инициирует его;
- с обязательным критерием снятия — что должно произойти, чтобы заглушку убрать.

## Формат записи

```markdown
### T-NNN — короткое описание

- Файл: `path/to/file`
- Согласовано: ГГГГ-ММ-ДД, с пользователем
- Причина: почему нельзя сделать правильно сейчас
- Критерий снятия: что должно произойти, чтобы убрать заглушку и эту запись
```

При снятии заглушки запись переносится из «Активные» в «Снятые» с датой снятия, а не удаляется — так же, как `reviews/critical-review.md` не удаляет закрытые пункты.
