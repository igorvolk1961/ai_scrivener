# Ревью сторонних ИИ-агентов

Каталог для результатов независимого ревью проекта внешними ИИ-агентами. Ревью не является источником истины: решения по его пунктам фиксируются в `docs/design-decisions.md`, требованиях и планах, а сам отчёт остаётся историческим артефактом.

## Формат

Один файл на ревью: `<YYYY-MM-DD>-<тема>.md` или содержательное имя, если файл уже существует и на него есть ссылки.

В начале файла указываются:

- дата ревью;
- агент/модель и режим (если известны);
- границы: какие документы и какая версия кода проверялись;
- статус: `актуально`, `закрыто`, `устарело`.

## Правила

- Закрытые пункты не удаляются: статус меняется на `закрыт` со ссылкой на артефакт с решением.
- Результаты ревью не редактируют канонические документы напрямую; изменения вносятся отдельно и проходят `make check`.
- Секреты, персональные данные и содержимое реальных документов в отчёты не попадают.

## Содержимое
