# Глоссарий

Выделено из `docs/raw_specification.md` §2 как самостоятельный артефакт системного анализа. Источник истины термина — здесь; остальные документы используют термины в этом значении без повторного определения.

| Термин | Определение |
|---|---|
| **ДЛ** | Должностное лицо — `Пользователь` с привязкой к `ФизическомуЛицу`, занимающий одну постоянную должность и, опционально, замещающий одну или несколько других (`docs/raw_specification.md` §4.1.3). |
| **Должность** | Штатная единица с набором обязанностей и местом в иерархии (`Справочник.Должности`). |
| **Действующие должности ДЛ** | Объединённый на дату набор: постоянная должность (`СведенияОПользователяхДокументооборот`) ∪ должности всех, кого ДЛ замещает на эту дату (`ДелегированиеПрав`). Обязанности резолвятся по этому набору, источник отдельной должности (постоянная/замещаемая) не важен. |
| **Замещение** | Исполнение обязанностей другой должности на период — не новый объект расширения, а штатный механизм делегирования прав Документооборота (`Catalogs.ДелегированиеПрав`). |
| **Должностные обязанности** | Формализованное описание действий ДЛ в различных ситуациях (`АИС_ДолжностныеОбязанности`), привязанное к паре (`ТипТриггера`, `ТипДействия`) для каждой действующей должности. |
| **Триггер** | Событие, требующее реакции ДЛ (входящий документ, таймер, распоряжение, бизнес-событие, ответ на запрос, истечение срока ожидания). |
| **Распоряжение** | Триггер и одновременно возможный прямой источник требуемого действия: указание вышестоящего ДЛ, письменное или устное (зафиксированное при регистрации как `ВнутреннийДокумент`), которое может задавать разовое действие или — через фиксацию в `АИС_РасписаниеТриггеров` — периодическое требование по таймеру. |
| **Плейсхолдер** | Именованный фрагмент шаблона документа, подлежащий заполнению данными. |
| **Источник данных** | Место, откуда берётся значение для плейсхолдера: БД документов, расчётный сервис, внешний API, другое ДЛ как держатель сведений. Решение ДЛ — отдельный способ заполнения, а не источник данных. |
| **Лист ожидания** | Справочник `АИС_ЛистОжидания` (не регистр сведений — нужен ссылочный тип) — незаполненные плейсхолдеры и неподтверждённые разделы, по которым отправлены запросы. |
| **Решение ДЛ** | Способ заполнения плейсхолдера (`РешениеДЛ` в `АИС_СпособыЗаполнения`), отличный от запроса факта: ДЛ формулирует управленческое решение, видя прецеденты, а не просто сообщает известное значение. |
| **Задача реагирования** | Штатная `Задача.ЗадачаИсполнителя` плюс запись `АИС_КонтекстЗадачИИ`. |
| **Эскалация** | Автоматическое формирование доклада о срыве сроков с анализом причин; направляется вышестоящему ДЛ после обязательной проверки (см. `docs/design-decisions.md` §14). |
| **АИС_** | Префикс объектов расширения; в проекте — «Автоматизированная интеллектуальная система» (AI Scrivener). |

## Аббревиатуры проекта и инфраструктуры

| Аббревиатура | Расшифровка | Пояснение |
|---|---|---|
| **API** | Application Programming Interface | Интерфейс взаимодействия сервисов; в проекте — HTTP API RAG-сервиса. |
| **CI** | Continuous Integration | Непрерывная интеграция; GitHub Actions. |
| **FR** | Functional Requirement | Функциональное требование в `requirements.yaml`. |
| **HTTP/HTTPS** | HyperText Transfer Protocol (Secure) | Протокол взаимодействия 1С с RAG/LLM. |
| **JSON** | JavaScript Object Notation | Формат обмена данными и ответов LLM. |
| **LLM** | Large Language Model | Большая языковая модель; DeepSeek, GigaChat, локальная модель. |
| **MVP** | Minimum Viable Product | Минимально жизнеспособный продукт. |
| **NFR** | Non-Functional Requirement | Нефункциональное требование. |
| **OCR** | Optical Character Recognition | Распознавание текста; Tesseract для окна 1С. |
| **RAG** | Retrieval-Augmented Generation | Генерация с поиском по внешнему индексу; Qdrant + эмбеддинги. |
| **RBAC** | Role-Based Access Control | Ролевое управление доступом; роли расширения. |
| **SQL** | Structured Query Language | Язык запросов к PostgreSQL. |
| **TLS** | Transport Layer Security | Шифрование HTTP-трафика. |
| **UUID** | Universally Unique Identifier | Уникальный идентификатор объектов метаданных и записей. |
