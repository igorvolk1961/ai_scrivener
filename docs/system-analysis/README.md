# Артефакты системного анализа

Подпапка объединяет документы, выделенные из `docs/raw_specification.md` в самостоятельные артефакты системного анализа. Исходная спецификация остаётся источником требований; документы ниже не вводят нового поведения, а фиксируют видение, терминологию, участников и сценарии.

- `view-and-scope.md` — видение и границы проекта (Vision & Scope).
- `glossary.md` — глоссарий; источник истины по терминам.
- `stakeholder-map.md` — карта стейкхолдеров и ролей.
- `use-cases.md` — варианты использования в формате актор/предусловие/поток.
- `c4-model.md` — C4-модель: контекст, контейнеры и компоненты.

Процессные диаграммы AS-IS и TO-BE остаются в `docs/process-diagrams.md`: это отдельный артефакт моделирования процессов, а не системного анализа в узком смысле.
