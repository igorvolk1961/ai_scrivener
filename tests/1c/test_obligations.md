# Тест приоритета обязанностей

Ручной сценарий проверки выбора должностной обязанности по характеристике триггера. Не относится к RLS и правам доступа.

> **Актуализация 2026-10-28:** `АИС_ДемоДанные` удалена; она больше не создаёт должности и пользователей. Базовый штат создаётся симулятором из `config/enterprise.json`; тестовые фикстуры ДЛ1/ДЛ2 и т.п. больше не создаются автоматически. Логины `ДЛ1`, `ДЛ2`, `Руководитель`, `Аудитор`, `Админ`, `БезРоли` — legacy-фикстуры; сценарии ниже требуют адаптации под фактических пользователей предприятия.

## Подготовка

1. Заполнить демоданные (`АИС_ЗаполнитьДемоДанные`) на копии демо-базы.
2. Убедиться, что у ДЛ есть:
   - общая обязанность без `Характеристика`;
   - специфичная обязанность с `Характеристика = Авария` и заполненным `ТребуемыйВидДокумента`.
3. Создать или выбрать триггер с характеристикой `Авария`.

## Сценарий

### O1. Специфичная обязанность выигрывает у общей

- Открыть задачу реагирования по триггеру с `Характеристика = Авария`.
- Определить выбранную `АИС_ДолжностныеОбязанности`.
- **Ожидаемо:** выбрана специфичная обязанность; при её отсутствии — общая.
- **Фактически:** не выполнено.
- **Статус:** [ ] пройден, [ ] не пройден.

## Итог

Сценарий требует ручного прогона на демо-базе; автоматический прогон в CI не выполняется.
