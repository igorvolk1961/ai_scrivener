# Тест параметров промптов

Ручной сценарий проверки того, что автошаблонизация читает промпт и параметры из базы, а не из кода.

## Подготовка

1. Применить расширение.
2. Выполнить **«АИС: Сервис» → «Заполнить промпты»** (или `POST /hs/ais-sim/prompts/seed`).
3. Убедиться, что в `Справочник.АИС_Промпты` есть запись `ФормированиеШаблонаПоДокументу`, а в `АИС_ПромптПараметры` — связанная с ней активная запись.

## Сценарий

1. Открыть `АИС_Промпты.ФормированиеШаблонаПоДокументу` и изменить текст, добавив однозначную фразу.
2. Создать внутренний документ без шаблона от имени `ГенДиректор`.
3. Убедиться, что `Программист1С` получил задачу `Согласовать шаблон: ...`, а в тексте задачи виден результат, соответствующий изменённому промпту.
4. Проверить, что в запросе к DeepSeek использованы модель, температура и лимит токенов из `АИС_ПромптПараметры`.

## Ожидаемый результат

- Промпт и параметры читаются из базы.
- Изменение текста промпта не требует изменения BSL.
- При отсутствии активного промпта шаблон не формируется, в журнал регистрации пишется ошибка.
