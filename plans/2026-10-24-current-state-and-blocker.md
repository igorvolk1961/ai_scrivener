## 4. Что происходит при запуске 1С

### 4.1. Доступ

Демо-база восстановлена из `DocMng_2_1_38_11_new.dt` (архив найден в `/home/igorvolk/tmp`).

Пользователь `Администратор`:

- имеет роли `Полные права` и `Администратор системы` (видно в отчёте «Список полномочий и ролей»);
- при этом в отчёте пусты:
  - «Общие разрешения политик доступа»;
  - «Специальные разрешения политик доступа»;
  - «Локальное администрирование».

Следствия:

- плитка «Права доступа» недоступна;
- команда «Все функции» не появляется, `Ctrl+Shift+F9` не помогает;
- в карточке бизнес-пользователя есть вкладки «Основное», «Исполняет роли», «Настройки», но нет вкладки прав;
- вкладка «Исполняет роли» пустая;
- вкладка «Настройки» — это настройки рабочего стола, не права.

Причина: в 1С:Документооборот доступ к разделам и административным командам дают не платформенные роли, а **профили/группы доступа**. У пользователя есть роли, но нет профиля доступа, поэтому административные разделы заблокированы. Без существующего администратора профиль не назначить — замкнутый круг.

### 4.2. Загрузка расширения

Полная XML-выгрузка расширения из EDT не загружается в базу:

- через Конфигуратор: «Загрузка не должна менять принадлежность основного объекта конфигурации»;
- через CLI полная загрузка создаёт пустое расширение или падает с segfault;
- UUID расширения в базе и в XML не совпадают:
  - XML: `ffd051e4-c455-4f69-8e4b-49c1c12b921a`;
  - ранее встречались UUID `305a4770-...`, `18e1b3ff-...`.

Обход: загрузка по частям через `LoadConfigFromFiles` с `-Extension`.

Успешно загружены:

- шаг 1: язык + `АИС_СпособыЗаполнения`;
- шаг 2: все перечисления;
- шаг 4: новые справочники;
- шаг 5: регистры;
- шаг 6: принятые справочники с ТЧ;
- шаг 7c: `АИС_ДемоДанные`, `АИС_ЗаполнитьДемоДанные`, `УстановкаПараметровСеанса`, `ПередНачаломРаботыСистемы`;
- шаг 8: регламентное задание `АИС_РазовоеЗаполнениеДемоДанных`.

Не загружаются:

- определяемые типы `АИС_АдресатЗапроса`, `АИС_РезультатЗадачи`, `АИС_ИсточникТриггера` — «Недопустимый тип» для базовых справочников `Пользователи`, `Должности`, `СтруктураПредприятия`;
- роли — загружаются молча пустыми (в выгрузке расширения ролей нет).

Временный обход для B4: в тестовой XML-выгрузке тип `АИС_ЛистОжидания.Адресат` заменён на прямые типы базовых справочников, роли исключены. Это только тестовый пакет, не штатная модель.

## 5. Итог блокера

B4/B5 нельзя выполнить по трём независимым причинам:

1. **Нет административного профиля доступа.** Пользователь с ролями не может открыть «Права доступа», «Все функции» и административные разделы.
2. **Расширение загружается только частично.** Полная XML-выгрузка EDT не применяется; определяемые типы и роли не загружаются.
3. **Регламентное задание не запускается.** Оно есть в расширении, но не зарегистрировано/не запланировано в ИБ; стартовый модуль расширения не вызывается.

## 6. Что делать дальше

### Вариант A — получить рабочего администратора (предпочтительно)

1. Взять у преподавателя логин/пароль администратора демо-базы или исходный `.dt` с настроенным профилем.
2. Войти этим администратором.
3. Открыть «Права доступа» и выдать `Администратору` профиль с полными правами.
4. После этого станут доступны «Все функции» и управление расширениями.

### Вариант B — восстановить демо-базу без создания нового пользователя ИБ

1. Развернуть `.dt` в новую файловую базу.
2. Не создавать нового пользователя ИБ вручную.
3. Запустить Enterprise и пройти начальную настройку/использовать демо-пользователя с готовым профилем.

### Вариант C — тестовый контур без прав 1С:ДО

1. Использовать тестовый пакет расширения без ролей и определяемых типов (шаги 1–8).
2. Запустить B4 через регламентное задание или внешнюю обработку.
3. Проверить только создание демоданных; B5 (права/RLS) в этом контуре не проверяется.

### После разблокировки

1. Загрузить полное расширение с определяемыми типами и ролями.
2. Проверить выгрузкой, что в расширении есть все объекты.
3. Запустить B4 и проверить `/tmp/kilo/b4-result.txt` и демоданные.
4. Прогнать `tests/1c/test_access.md` и `tests/1c/test_obligations.md`.
5. Закоммитить регламентное задание и обновить статус Этапа B.
