## Что уже реализовано и закоммичено

### Расширение 1С:Документооборот

- Папки документов:
  - справочники `АИС_ПапкиДокументов`, `АИС_ДокументыВПапках`;
  - HTTP `/folders/ensure`, `/folders/place`, `/folders/documents`;
  - открытие документа из папки, кнопка в auto command bar.
- Оргструктура:
  - `POST /org-structure/department`, `GET /org-structure`;
  - агентские инструменты `create_department`, `list_departments`,
    `list_employees`; поддержка иерархии подразделений.
- Отмена и утверждение документов:
  - `ОтменитьДокумент` через `СвязиДокументов.СоздатьСвязь` +
    `УстановитьРеквизитыПриДобавленииСвязи` (флаг `НеДействует`);
  - `УтвердитьДокумент` через штатное состояние `Утвержден`;
  - `/documents/cancel`, `/documents/approve`.
- Разделы документа (базовый backend):
  - справочник `АИС_РазделыДокумента` с иерархией и `Содержание`;
  - шаблонные плейсхолдеры `АИС_Плейсхолдеры` с `Вид=Раздел`;
  - `POST /sections/action` с действиями
    `СоздатьДокумент|Список|Назначить|Записать|Подраздел|Подтвердить|Собрать`;
  - модуль `АИС_РазделыДокументов`:
    `СоздатьДокументПоШаблону`, `НазначитьРаздел`,
    `ЗаписатьСодержаниеРаздела`, `СоздатьПодраздел`, `ПодтвердитьРаздел`,
    `СобратьДокумент`, `ПолучитьРазделы`.
- Проверки сценария в симуляторе:
  - `owner-2a`: старая концепция `НеДействует`, новая `Утвержден`, отдельный
    приказ об утверждении от нужного автора;
  - `completion.requires_approval` вместо жёсткого `concept_revision`;
  - ограничение доступных инструментов по роли/этапу.

### Симулятор

- Агентские инструменты `manage_document_sections`, `approve_document`,

## Известные ограничения и риски

- `Задача.ЗадачаИсполнителя.Предметы.Предмет` не поддерживает
  `СправочникСсылка.АИС_РазделыДокумента`. Используется предмет-документ, а
  раздел хранится в `АИС_РазделыДокумента.Задача` / `Распоряжение`.
- Добавление документов в owners `АИС_РазделыДокумента` вызывало segfault
  1С Designer. Owners оставлены шаблонными; для черновиков используется
  служебный шаблон, документ хранится в `АИС_РазделыДокумента.Документ`.
- `АИС_РазделыДокумента` должен оставаться `<hierarchical>true</hierarchical>`,
  иначе поле `Родитель` не участвует в запросах.
- Загрузка расширения при открытом клиенте 1С или активных Apache workers
  может приводить к segfault / ошибке лицензии. Надёжный порядок: закрыть
  клиент, `pkill -KILL -x apache2`, дождаться завершения, затем
  `scripts/build/load_extension.sh file`.
- Нет UI редактора шаблонов/дерева разделов — осознанно отложено.
- Преобразование документа в шаблон (пункт 4 исходного плана) отложено.
- Нет инструмента поиска/списка шаблонов для агента; при необходимости
  добавлять `search_templates` / `list_templates`.
